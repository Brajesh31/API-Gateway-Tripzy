## Maintainer responsibilities

- Keep project status and implementation claims accurate.
- Review code, documentation, workflow, and dependency changes.
- Require verified upstream contracts before enabling routes.
- Ensure security-sensitive changes receive appropriate review.
- Keep issue and pull request discussions constructive.
- Coordinate release notes, compatibility, and deprecation.
- Review unresolved technical debt and security advisories.
- Update documentation when implementation changes.

## Service ownership

Tripzy upstream service owners are not identified in this repository. They must be added only after the relevant team confirms ownership and an escalation contact.

## Adding a maintainer

A maintainer addition should include the person's GitHub account, scope of authority, review responsibilities, and approval from the current project owner. Update CODEOWNERS and governance documentation together.
